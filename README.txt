GITHUB PAGES:
1. Create a new GitHub repository, e.g. jamshad-portfolio.
2. Upload ALL files and keep the images folder.
3. Go to Settings > Pages.
4. Select Deploy from branch, choose main, / (root), then Save.
5. GitHub will provide the live website link.

Before publishing, replace the LinkedIn placeholder in index.html with your real LinkedIn URL.
You can also add a PDF CV and a real project image gallery later.
